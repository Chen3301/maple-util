메이플 경매장 → 환산주스탯 자동 등록 유틸
===========================================

경매장에서 검색한 매물 상위 N개를 환산주스탯(maplescouter) 아이템 메이커에
자동으로 입력해서, 가격 대비 데미지 효율을 한 번에 비교할 수 있게 해주는 프로그램입니다.


[사용법]

1. 압축을 풀고 MapleAuctionUtil.exe 실행
   - 처음 실행하면 브라우저(약 200MB)를 자동으로 받습니다. 몇 분 걸릴 수 있어요.
   - 윈도우가 "알 수 없는 게시자" 경고를 띄우면 [추가 정보] → [실행]을 누르세요.
     (서명 안 된 개인 제작 프로그램이라 뜨는 정상적인 경고입니다)

2. ★ 처음이라면 [넥슨 로그인] 버튼을 먼저 누르세요. (최초 1회)
   - 전용 브라우저가 열리면 넥슨 로그인 → 경매장 입장 캐릭터 선택까지 진행
   - "로그인 완료!" 가 뜨면 창이 닫히고 세션이 저장됩니다.
   - 환산주스탯 계정이 있으면 [환산주스탯 로그인]도 같은 방식으로 해두면 됩니다. (선택)

3. 상위 몇 개 / 본인 직업을 고르고 [실행]

4. 열린 경매장 창에서 원하는 아이템을 직접 검색하세요.
   - 검색 결과가 나오는 순간 프로그램이 자동으로 인식합니다.
   - 정렬(가격 낮은 순 등)과 필터를 원하는 대로 걸고 검색하면,
     화면에 보이는 순서대로 위에서부터 N개를 가져옵니다.

5. 새 탭이 열리면서 매물이 환산주스탯 보관함에 등록됩니다. (거의 즉시)
   - [스펙업 순서 등록까지 자동으로]를 켜두면, 보스컷 페이지에서
     아이템별로 장착 → 적용 → 이름(예: 도미네이터1)·가격 입력 → 등록하기를
     자동 반복합니다. 끄면 보관함까지만 담습니다.

6. ★ 여러 아이템을 비교하려면 브라우저를 켜둔 채 [실행]을 반복하세요.
   - 로그인·캐릭터 선택을 다시 할 필요가 없습니다.
   - 보관함이 초기화되지 않고 계속 누적됩니다.
     예) 펜던트 5개 담고 → 다시 [실행] → 귀고리 검색해서 5개 더 담기

7. 다 담았으면 환산주스탯 탭에서 [아이템 적용하기]를 눌러
   효율보스컷 페이지에서 가격 대비 효율을 한 번에 비교하세요.


[알아둘 점]

- 이 프로그램은 전용 브라우저를 사용합니다.
  로그인 정보와 즐겨찾기는 이 브라우저에만 저장되고,
  평소 쓰는 크롬은 전혀 건드리지 않습니다.
  (그래서 결과 확인도 프로그램이 띄운 창에서 하시면 됩니다.
   즐겨찾기는 껐다 켜도 그대로 남아 있습니다)

- 경매장 검색은 넥슨 계정당 하루 100회 제한이 있습니다.
  프로그램 실행 1회당 검색 1회를 사용합니다.

- 보관함은 계속 누적되므로, 완전히 새로 비교하고 싶을 때는
  환산주스탯 보관함의 [전체삭제]로 정리하고 시작하세요.

- 데미지와 무관한 잠재옵션(최대 MP, 점프력 등)은
  환산주스탯에 해당 항목이 없으면 생략됩니다. 효율 계산에는 영향 없습니다.

- 환산주스탯이 "에러가 발생했습니다" 화면을 띄우면 프로그램이 자동으로 재시도합니다.
  그래도 계속 나오면 그 탭에서 [하드리셋]을 누르세요.
  (사이트에 저장된 데이터를 초기화합니다 — 기존 즐겨찾기는 지워집니다)

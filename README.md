# MapleUtil

메이플스토리 경매장 매물을 [환산주스탯](https://maplescouter.com) 아이템 메이커에 자동으로 등록해,
**가격 대비 데미지 효율**을 한 번에 비교할 수 있게 해주는 윈도우 유틸리티입니다.

경매장에서 아이템을 검색하면 매물의 스타포스·추가옵션·주문서 작·잠재능력·에디셔널·가격을
그대로 읽어와 보관함에 등록하고, 보스컷의 **스펙업 순서 등록**까지 자동으로 처리합니다.

## 설치

1. [Releases](../../releases)에서 `MapleUtil.zip`을 받아 압축을 풉니다.
2. `MapleUtil.exe` 실행. 첫 실행 시 브라우저(약 200MB)를 자동으로 내려받습니다.
3. 윈도우가 "알 수 없는 게시자" 경고를 띄우면 **추가 정보 → 실행**을 누르세요.
   (개인이 만든 서명 없는 프로그램이라 뜨는 정상적인 경고입니다)

## 사용법

1. **[실행]** 을 누르면 전용 브라우저가 열립니다. 처음이라면 넥슨 로그인 후 캐릭터를 선택하세요.
2. 열린 경매장 창에서 **원하는 아이템을 직접 검색**합니다. 정렬·필터는 자유롭게 쓰세요.
3. 검색 결과가 나오면 화면에 보이는 순서대로 상위 N개를 자동으로 등록합니다.
4. **연속 모드**가 켜져 있으면 계속 검색하는 대로 보관함에 누적됩니다.
5. 다 담았으면 환산주스탯에서 결과를 비교하세요.

### 옵션

| 옵션 | 설명 |
| --- | --- |
| 캐릭터 자동 사용 | 경매장에 입장한 캐릭터의 닉네임·직업을 그대로 적용 |
| 상위 N개 | 검색 결과에서 가져올 매물 수 |
| 이름 접미사 | 같은 아이템 구분 방식 — `번호`(도미네이터1,2) 또는 `가격`(도미네이터 235억) |
| 스펙업 순서 등록 | 아이템별로 장착 → 적용 → 등록까지 자동 반복 |
| 연속 모드 | 한 번 실행으로 검색할 때마다 계속 등록 |

## 알아둘 점

- 경매장 검색은 **넥슨 계정당 하루 100회** 제한이 있습니다. 프로그램이 몰래 추가 검색을 하지는 않습니다.
- 전용 브라우저를 사용하므로 **평소 쓰는 크롬은 건드리지 않습니다.**
  로그인 정보는 `%LOCALAPPDATA%\MapleAuctionUtil` 에 저장되어 새 버전으로 덮어써도 유지됩니다.
- 환산주스탯 보관함은 브라우저에 저장되는 방식이라, 이 프로그램이 띄운 창에서 확인해야 합니다.

## 직접 빌드하기

```powershell
python -m venv venv
.\venv\Scripts\pip install playwright pyinstaller pillow
.\venv\Scripts\playwright install chromium
powershell -File build.ps1
```

`build.ps1` 은 아이콘 변환 → 빌드 → 자체 점검 → 배포용 zip 생성까지 한 번에 수행합니다.
아이콘을 바꾸려면 `icon.png`(정사각형 권장)를 교체하고 다시 빌드하면 됩니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `main.py` | 경매장 매물 수집, 환산주스탯 등록, 스펙업 순서 등록 |
| `gui.py` | 화면 |
| `widgets.py` | 커스텀 위젯(둥근 버튼, 토글, 그라데이션 헤더) |
| `make_icon.py` | 아이콘 규격 변환 |
